# Mercado Ahora - Manual de usuario borrador

Este manual es un primer borrador para acompañar el cierre del MVP. Puede ampliarse con capturas y casos reales cuando finalice la ronda de pruebas.

## 1. Comprador

### Crear cuenta

1. Ingresar a Mercado Ahora.
2. Seleccionar "Crear cuenta".
3. Completar nombre, email y contraseña.
4. Confirmar el email cuando llegue el correo de verificación.

### Buscar productos

1. Entrar a "Categorías" o usar la lupa.
2. Escribir el producto buscado, por ejemplo "miel".
3. Filtrar por categoría o provincia si corresponde.
4. Abrir la ficha del producto para ver precio, stock, productor y formas de entrega.

### Guardar favoritos

1. Iniciar sesión.
2. Presionar el icono de corazón en un producto.
3. Consultar los guardados desde "Favoritos".

### Comprar

1. Abrir la ficha del producto.
2. Elegir "Comprar ahora" o "Agregar al carrito".
3. Revisar "Finalizar compra".
4. Confirmar datos de entrega y nota al productor.
5. Crear el pedido.

Los pagos y entregas se coordinan manualmente por ahora. Mercado Ahora registra el pedido y permite al productor cambiar los estados.

### Corregir stock en checkout

Si el stock cambió desde que el producto se agregó al carrito, la pantalla de confirmación permite:

- Reducir la cantidad.
- Ajustar al stock disponible.
- Eliminar el producto.
- Reintentar la confirmación sin abandonar la pantalla.

### Ver pedidos y devoluciones

1. Entrar a "Mis pedidos".
2. Abrir el detalle.
3. Revisar estado e historial.
4. Solicitar devolución si el pedido cumple las condiciones.
5. Ver el estado de la devolución desde "Mis devoluciones".

## 2. Productor

### Solicitar convertirse en productor

1. Iniciar sesión como comprador.
2. Elegir la opción para vender o convertirse en productor.
3. Completar la postulación.
4. Esperar aprobación administrativa.

### Crear producto

1. Entrar al panel del productor.
2. Seleccionar "Mis productos".
3. Crear un producto.
4. Completar información básica: nombre, categoría, precio en pesos, stock, unidad, provincia/localidad y descripción.
5. Subir imágenes.
6. Publicar cuando esté listo.

### Gestionar productos

Desde "Mis productos" el productor puede:

- Editar.
- Pausar.
- Reactivar.
- Eliminar si no tiene historial de pedidos.
- Ver la publicación pública.

Si administración deja una observación de moderación, aparecerá como aviso para corregir la publicación.

### Gestionar pedidos

1. Entrar a "Pedidos".
2. Abrir el pedido.
3. Revisar comprador, productos, total y datos de entrega.
4. Actualizar estado: pendiente, confirmado, en preparación, enviado, entregado o cancelado.
5. Usar "Enviar mensaje al comprador" para coordinar detalles.

### Devoluciones

El productor puede consultar devoluciones vinculadas a pedidos que contienen sus productos. La resolución final queda en manos de administración.

## 3. Administrador

### Usuarios

El administrador puede:

- Buscar usuarios.
- Ver rol y estado.
- Cambiar estado.
- Restablecer contraseña temporalmente como respaldo.
- Acceder a las publicaciones de un productor desde "Ver publicaciones".

### Productores

El administrador puede:

- Revisar postulaciones.
- Aprobar productores.
- Rechazar productores.
- Ver información básica del emprendimiento.

### Productos y moderación

El administrador puede:

- Ver todos los productos.
- Identificar el nombre comercial del productor, usuario y email.
- Buscar por producto, productor, usuario o email.
- Filtrar por productor.
- Ver la publicación pública.
- Editar campos clave.
- Pausar, reactivar, rechazar o eliminar.
- Crear observaciones de moderación.
- Notificar al productor cuando debe corregir una publicación.

### Pedidos

El administrador puede:

- Ver pedidos.
- Abrir detalle.
- Revisar comprador, productos, total, estado e historial.
- Actualizar estado manualmente.

### Devoluciones

El administrador puede:

- Ver solicitudes.
- Revisar motivo y detalle.
- Aprobar, rechazar o completar.
- Marcar el pedido como devuelto cuando la devolución se completa.

## 4. Alcance actual del MVP

El MVP permite validar el flujo completo de publicación, búsqueda, carrito, compra manual, pedidos, chat, devolución y administración básica.

Queda fuera del MVP:

- Mercado Pago.
- Envíos automáticos.
- Reseñas públicas.
- Notificaciones avanzadas.
- Soporte con tickets.
- Impersonación completa de usuarios.
